# 💰 Dividend Logic & Implementation Guide

## 1. Overview
This document outlines the **Institutional Standard Dividend Logic** implemented in the UKOMBOZI Table Banking System. The system uses a **Bi-Monthly Average Share** method to ensure fair distribution and prevent end-of-year "dumping" (depositing large sums just to qualify for dividends).

## 2. Core Formulas

### A. Average Shares (The Basis)
Instead of using the current share balance, the system calculates the average of shares held at the end of every other month.

**Formula:**
```
Average Shares = (Jan + Mar + May + Jul + Sep + Nov) ÷ 6
```
*   **Why?** Rewards consistency throughout the year.
*   **Source:** `transactions` table (Simulated in current module).

### B. Total Return Fund (TRF)
This represents the **Gross Income** generated by the group.

**Formula:**
```
TRF = Bank Interest + STL Interest + LTL Interest + Penalties + Other Income
```
*   **Includes:** Only earnings (Interest/Fines).
*   **Excludes:** Principal repayments, Savings deposits.

### C. Available Profit (AP)
The actual amount available for potential distribution after costs.

**Formula:**
```
AP = TRF − Expenses − Reinvested Loans
```
*   **Expenses:** Bank charges, transport, stationery, etc.
*   **Reinvested Loans:** Money plowed back into the loan fund (capitalization).
*   **Rule:** If `AP <= 0`, dividends are impossible.

### D. Profit to Share Out (PSO)
The specific portion of profit designated for members.

**Formula:**
```
If Group Age > 1 Year:
    PSO = AP × 75%
Else:
    PSO = AP × 50%
```
*   **Governance Rule:** New groups must retain more earnings to build capital. Older groups can pay out more.

### E. Dividend Rate (The Multiplier)
The value generated by a single share unit.

**Formula:**
```
Dividend Rate = PSO ÷ Total Group Average Shares
```
*   **Result:** returns amount in KES per share.

### F. Member Dividend
The final paycheck for a member.

**Formula:**
```
Dividend = Member Average Shares × Dividend Rate
```

## 4. How to Use
1.  Navigate to **Dividends** from the sidebar.
2.  Input the **Financials** (Interest earned from Bank, STL, LTL, etc.) on the left panel.
3.  Input **Expenses** and **Reinvested Amounts**.
4.  The system calculates **Available Profit**.
5.  Enter/Confirm the **Share Balances** for members for the 6 key months.
6.  The system automatically calculates the **Dividend Amount** for each member.
7.  Click **Save & Post** (future integration) to credit member savings.
